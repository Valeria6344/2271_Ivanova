### Задание 1 **(2)**
*Рассмотрим следующую программу.*
```
d = {'sep': ',' , 'end': '\n'}
l = ['Утопия', 14, 'Вселенная', 25]
print (l, d)
print (*l, d)
print (*l, *d)
print (*l, **d)
```
*Объясните результаты ее работы.*

*При устном ответе на вопросы вам потребуется рассказать, что такое "Утопия 14" и "Вселенная 25".*

1. Команда: `print (l, d)`. Передаются две переменные без распаковки, поэтому выводится список и словарь целиком, как и записаны. Получается: `['Утопия', 14, 'Вселенная', 25] {'sep': ',', 'end': '\n'}`.
2. Команда : `print (*l, d)`. Здесь `*` выполняет распаковку списка. Вместо передачи одного списка передается в print четыре отдельных элемента. Получается: `Утопия 14 Вселенная 25 {'sep': ',', 'end': '\n'}`
3. Команда: `print (*l, *d)`. Тут распаковываются и список и словарь. При одной `*`, распаковывется словарь по его ключам, поэтому строки выводятся как обычные слова. Получается: `Утопия 14 Вселенная 25 sep end`
4. Команда: `print (*l, **d)`. Две `**` передает элементы словаря как именнованные аргементы. Теперь sep=',' устанавливает `,` , а end='\n' переход на новую строку. Получается: `Утопия,14,Вселенная,25`

### Задание 6 **(2)**

*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.* 

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

```
def gen(n):
    while n != 1:
        yield n
        n = n // 2 if n % 2 == 0 else 3 * n + 1
    yield 1
print(*gen(7))
```

```

    ...
```
*Ниже приведены примеры использования генератра.*
```
>>> print (*every_other([10, 20, 30, 40, 50]))

>>> print(*every_other(range(10)))
```

```
def every_other (seq):
    it = iter(seq)
    flag = True
    x = next(it, None)
    while x != None:
        if flag:
            yield x
        flag = not flag
        x = next(it, None)
print (*every_other([10, 20, 30, 40, 50]))
print(*every_other(range(10)))
print(*every_other(iter(range(10))))
print(sum(every_other(map(int, input().split()))))
```

###  Задание 10 **(1)**
*Какие из указанных функций и методов Python соответствуют определению чистых функций?
В случае отрицательного ответа требуется дать пояснение.*

* **file.readline|** — *чтение строки из файла.*
* **len** — *определение длины строки или количества элементов в контейнере.*
* **list.append** — *добавление в список нового элемента.*
* **sum** — *нахождение суммы.*
* **sorted** — *построение сортированного списка.*
* **list.sort** — *сортировка списка.*
* **random.randint** — *генерация случайного целого числа.*
* *Разворот списка.*
```
def rev(x):
    return x[::-1]
```
* *Выбор нескольких элементов из хвоста списка.*
```
tail_len = 3
def tail(x):
    return x[-tail_len:]
```

К чистым функциям относятся len, sum, sorted и rev(x). Потому что, во первых эти функции при одних и тех же входных аргументах они всегда возвращают один и тот же результат, во вторых они не изменяют переданные им данные.

• file.readline() — не чистая. При каждом новом вызове для одного и того же файла метод возвращает следующую строку, а не одну и ту же. Он изменяет внутреннее состояние файлового объекта, сдвигая указатель текущей позиции чтения.
• list.append — не чистая. Метод изменяет исходный список на месте. Всегда возвращает None вместо нового списка.
• list.sort — не чистая. В отличие от sorted, этот метод сортирует сам исходный список на месте и возвращает None.
• random.randint — не чистая. При вызове с одинаковыми границами функция возвращает разные значения и меняет внутреннее состояние генератора случайных чисел. 
• tail(x) — не чистая. Функция зависит от глобальной переменной tail_len, которая не передаётся в неё как аргумент. Если значение tail_len изменится в основной программе, вызов tail(x) с тем же самым списком x вернёт другой результат.

###  Задание 11 **(2)**
*Рассмотрите следующую функцию.*
```
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
*Что передается в функцию* **toint**? *Что возвращает эта функция?*
*Что делает функция* **wrapper**?
*Придумайте несколько примеров использования* **toint**.

Функция toint принимает другую функцию (например fun), поведение которой мы хотим изменить или расширить.
Она возвращает новую функцию wrapper, которая заменяет собой исходную функцию fun.
Функция wrapper принимает произвольное количество позиционных аргументов, применяет к каждому из них функцию int с помощью map(int, args), дальше передаёт полученные целые числа в исходную функцию fun. Возвращает результат её работы.

```
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
@toint
def add(a, b):
    return a + b
print(add("2", "3"))
@toint
def multiply(a, b, c):
    return a * b * c
print(multiply("2", "3", "8"))
@toint
def subtract(a, b):
    return a - b
print(subtract("23", "3"))
```
